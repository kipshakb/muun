# MUUN26 — сайт

Статический мультиязычный лендинг (ky / ru / en). Контент и разметка — в одном месте,
готовые страницы генерируются в `dist/`.

## Структура

```
src/
  template.html   # единая разметка с {{плейсхолдерами}} + inline-скрипты
  i18n.json       # тексты + мета (title/description) на каждый язык
  styles.css      # @tailwind + палитра/анимации проекта
assets/           # картинки-источники (логотип, фазы луны, арена, roadmap…)
tailwind.config.js
build.mjs          # сборка: генерит страницы + компилит и хеширует CSS + копирует assets
dist/              # РЕЗУЛЬТАТ — это заливается на хостинг (не редактировать вручную)
```

## Как редактировать

- **Тексты/переводы** → `src/i18n.json` (ключи одинаковые во всех языках).
- **Разметку/блоки** → `src/template.html`.
- **Цвета/шрифты** → `tailwind.config.js`, глобальные стили/анимации → `src/styles.css`.
- **Картинки** → положите в `assets/`, сошлитесь как `/assets/имя.jpg` в шаблоне.

⚠️ Домен для canonical / hreflang / og задаётся в `build.mjs` → `SITE_URL`
(сейчас `https://placy.kz`).

## Сборка

```bash
npm install      # один раз
npm run build    # → собирает dist/
```

## Деплой на Plesk (ручная заливка)

1. `npm run build`.
2. В Plesk → **File Manager** зайдите в `httpdocs`, удалите старое содержимое.
3. Загрузите **содержимое** папки `dist/` (файлы + папка `assets/`, папки `ru/`, `en/`,
   файл `.htaccess`) в корень `httpdocs`. Важно: заливать содержимое `dist/`, а не саму папку.
4. Plesk → **SSL/TLS Certificates** → выпустить бесплатный **Let's Encrypt** (HTTPS).

Готово. Языки доступны по адресам:
`/` (ky), `/ru/`, `/en/`. Переключатель языков ведёт между ними и запоминает выбор.

> Сайт полностью автономный: Tailwind скомпилирован в `assets/styles.<hash>.css`,
> все картинки — локальные. Внешне подключаются только шрифты Google Fonts.

> Если Plesk обслуживает статику через nginx и `.htaccess` игнорируется — те же
> правила кэша/gzip можно вписать в **Hosting Settings → Apache & nginx Settings →
> Additional nginx directives**.
