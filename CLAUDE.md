# MUUN26 — сайт (muun.kg)

Статический мультиязычный сайт мероприятия MUUN26 (ky / ru / en).
Репозиторий: github.com/kipshakb/muun, основная ветка — `main`.

## Правила работы с git (важно)

- **Никогда не коммить и не пушить без прямой команды пользователя.**
- «Закоммить» = только локальный коммит, без отправки в GitHub.
- **«Пуш» / «запушь»** = то же, что «Commit + Sync Changes» в Antigravity:
  1. собрать проект (`npm run build`) — если сборка падает, остановиться и
     сообщить, ничего не отправлять;
  2. закоммитить все незакоммиченные изменения (если они есть);
  3. `git pull --rebase origin main`, затем `git push origin main`.
- **Push в `main` = публикация на живой сайт**: Vercel подключён к GitHub и
  автоматически пересобирает и деплоит сайт после каждого push в `main`.
  После push сообщить пользователю, что деплой запущен.
- Рискованные или экспериментальные изменения — в отдельной ветке, если
  пользователь об этом попросил; в `main` вливать только по его команде.
- Стиль сообщений коммитов: `fix: website vX.Y.Z (краткое описание)`.
  Номер версии — следующий после последнего коммита (`git log --oneline -5`).
  Крупное изменение → увеличить Y, мелкая правка → увеличить Z.
- Не коммитить `dist/`, `node_modules/`, `scratch/`, `*.txt` (они в `.gitignore`).

## Команды

```bash
npm install        # один раз
npm run build      # собрать сайт в dist/
npm run dev        # локальный просмотр dist/ на http://127.0.0.1:3000
```

После правок всегда пересобирать (`npm run build`), потом проверять в браузере.
Сборка обращается к API регистрации за числом оставшихся мест; без сети берётся
запасное значение — это не ошибка.

## Структура

- `templates/eventis_raw.html` — основа главной страницы (копия Framer-вёрстки).
- `scripts/build_framer_i18n.mjs` — собирает главную из шаблона, подставляет
  тексты и блоки из `scripts/*.mjs` (программа, новости, пресса, форма
  регистрации, соцсети, мобильное меню и т.д.).
- `scripts/form_endpoints.mjs` — адреса Google Apps Script для форм.
- `scripts/optimize_assets.mjs` — оптимизация картинок при сборке.
- `src/i18n.json` — тексты и мета на всех трёх языках (ключи одинаковые).
- `src/template.html`, `src/news.html`, `src/press.html` — шаблоны страниц.
- `src/scheme.html` (или `kurultai.html`) — закрытая схема зала
  (`/scheme`, `/kurultai`), публичных ссылок на неё на сайте нет.
- `src/styles.css`, `tailwind.config.js` — стили и палитра.
- `assets/` — картинки-источники. `dist/` — результат сборки, вручную не править.
- `apps-script/*.gs` — серверная часть форм (Google Apps Script). Изменения в
  этих файлах **не** публикуются через git — их нужно вручную вставить в
  редактор Apps Script и задеплоить. Напоминать об этом пользователю.
  **Секреты (токены, ключи) никогда не писать в код** — репозиторий публичный.
  Токен Telegram берётся из свойств скрипта (`TELEGRAM_BOT_TOKEN`,
  `TELEGRAM_CHAT_ID` в «Настройки проекта → Свойства скрипта»).
- `vercel.json` — заголовки кэша и безопасности для Vercel. `.htaccess`,
  который генерирует `build.mjs`, на Vercel не действует (остался от Plesk).
- Известная проблема: React из движка Framer видит расхождения с готовым HTML
  (ошибки #418/#422 в консоли) и перерисовывает страницу. На медленном интернете
  это видно как мигание или временный шаблон; один раз страница упала целиком
  в пустую. Любые правки HTML внутри блоков Framer проверять на этот эффект.
- `build.mjs` — главный скрипт сборки; домен задан в `SITE_URL`.

## Тексты

Любой видимый текст меняется во всех трёх языках (ky, ru, en). Если перевода
нет — спросить пользователя, а не оставлять пустым или на одном языке.
